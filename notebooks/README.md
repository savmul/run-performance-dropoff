# Notebooks

This folder contains the Jupyter notebooks used for the Run Performance Drop-Off analysis.

## Notebooks
- **01_data_inspection.ipynb** — initial inspection and validation of the Strava export data
- **02_dropoff_analysis.ipynb** — main analysis of pace/effort patterns and performance drop-off
