# SQL Queries

This folder contains SQL queries used to support exploratory analysis and validation for the Run Performance Drop-Off project.

## Purpose
SQL was used alongside Python to:
- Filter runs by distance and effort criteria
- Validate subsets used in notebook analysis
- Perform quick aggregations and sanity checks

## Structure
- `queries/` — individual SQL files, each focused on a specific analytical question

The primary analysis is documented in the Python notebooks. SQL queries serve as supporting validation and exploration.
