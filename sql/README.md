# SQL

This folder contains SQL queries used for exploratory analysis and validation during the **Run Performance Drop-Off** project.

## What SQL is used for in this project

- Filtering runs by criteria (distance thresholds, date ranges)
- Comparing segments (long vs. non-long runs)
- Quick aggregations to validate trends observed in Python
- Sanity checks on cleaned datasets (missing values, outliers)

## Folder contents

- `queries/`
  - A collection of `.sql` files organized by analysis question

## Notes

- SQL was used as a complementary tool alongside Python/pandas.
- Queries are written to be readable and reusable (commented, clearly named).
